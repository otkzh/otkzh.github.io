# 文字サイズと可読性の基準

50 代を含む幅広い利用者が読みやすいよう、サイト全体で以下の文字サイズを基準にする。

## 基準

- 標準本文: 18px
- 最低本文: 17px
- 小さい文字: 15〜16px
- 14px 以下は禁止
- ボタン・リンクなど操作に関わる文字: 16px 以上。SP では 17px を推奨
- 行間: 1.7〜1.9
- 本文色: `#222`〜`#333`程度
- 薄いグレー文字を小さくして情報量を補う表現は避ける

## 今回の調整

- `src/layouts/BaseLayout.astro` のルート文字サイズを 18px、本文の行間を 1.8、基本文字色を`#222`に設定
- Astro ページの補助文字を 15px 以上に引き上げ、ボタン・リンクを 16px 以上に調整
- SP 表示の本文・説明文・操作リンクも同じ基準に統一
- メモ本文を 18px 前後、行間 1.9 で表示
- 薄いグレーだった説明文・ラベル類を`#333`程度へ変更
- `public/map_embedded.html` と `public/mapcap.html` の操作文字・帰属表示も基準に合わせて調整

## 実装時の目安

`BaseLayout.astro` ではルート文字サイズを 18px としているため、15px 相当には`0.833rem`以上、16px 相当には`0.889rem`以上を使用する。現在の補助文字では余裕を持たせて`0.875rem`（15.75px）以上を目安にする。

文字サイズを変更した場合は、以下で Astro のチェックを実行する。

```bash
npm run check
```

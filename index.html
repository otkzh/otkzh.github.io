WEB APPS / EXPERIMENTS03 / 03

MAP / MOTION / SOUND

つくったもの

地図に書く。傾けて鳴らす。音を眺める。
AIと対話しながら、バイブコーディングでつくった3つのWebアプリ。

＋

01 / MAP

Map Capture

地図にメモや手書きを添えて、画像に保存。現在地や気になった場所を、ひと目で伝えられます。

現在地取得は位置情報の許可が必要です。

地図に書いてみる ↗仕組みを読む →
〜

02 / MOTION

Gyro Beat

スマホを傾けるとテンポと音程が変わり、振ると打楽器の音。動きで演奏する、小さな電子楽器です。

音が出ます。マウスやタッチでも操作できます。

傾けて鳴らしてみる ↗仕組みを読む →
◎

03 / SOUND

Dynamic Engine

マイクで拾った音に合わせて、光の輪や粒子が動きます。声や音楽の強弱を、映像として眺める実験です。

マイクの使用許可が必要です。

音を映像にしてみる ↗仕組みを読む →

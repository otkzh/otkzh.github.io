# 18pxから始める、読みやすい文字設計

文字の印象を整えるとき、見出しの大きさには目が向きやすい。けれども、サイトを読み続けられるかを決めるのは本文だ。このサイトでは、50代を含む幅広い利用者を想定し、本文18pxを出発点にしている。

本文は原則17pxを下回らず、行間は1.7〜1.9程度にする。Memoのように文章を読む場所では、行間を広めに取る。文字色は真っ黒に固定せず`#222`から`#333`程度を使うが、小さな文字を薄いグレーにして情報量を詰め込む方法は避ける。

## 大きい文字だけでは解決しない

同じ18pxでも、行が長すぎると視線を戻しにくい。カードでは列幅を抑え、長文ページでは本文幅を限定する。見出しは大きくできても、本文との間隔や改行位置が不自然なら、読みやすさは上がらない。

文字サイズ、行間、行長、色の差を一組として考える。数字ひとつを基準にするのではなく、文章を読む時間まで含めて調整することが、可読性の設計になる。
